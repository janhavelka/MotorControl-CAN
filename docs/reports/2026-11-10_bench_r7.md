Observed, drive reports and the attendant's own observations, one firmware, two specimens:

- **Mode 3 enable report (S17):** on both nodes the first report of operation enabled came between 0.378 s and 0.728 s after word 15's acknowledgement (the bounds are the reads before and after). Mode 1's report came 0.85 to 0.88 s after it.
- **Start order (Q03):** `60FF`, `6083`, `6084`, then words 6, 7, 15, each acknowledged, started the motor at word 15, not before: `606C` was 0 and `6064` unchanged in every cycle before the enable report.
- **Rate and sign:** `606C` read 5 while running; `6064` rose about 99 counts/s on both nodes. With `2201=1000` counts per motor turn, that is 5.95 rpm against the commanded 6. `60FF=+6` turned both shafts counter-clockwise, viewed facing the shaft end. For trial 1009 the user had answered "I believe it was clockwise, but not 100% sure"; these two runs were watched deliberately.
- **Displacement:** both nodes ended at 1131 counts; the attendant estimated 1.1 turns on node 2, consistent with 1000 counts per turn. This is a visual estimate, not a measurement of scale.
- **HALT in mode 3 (Q12):** the HALT from the running run left at its due time on both nodes. Within 28 ms both still reported running (`C037`/`0004`); 4.04 s later node 2 reported halted in place (`9437`/`0001`), and both read `606C=0` at 1131 afterwards. The drive stayed enabled and in mode 3.

Not established: what "faster" and "quite sketchy" mean physically. A hypothesis, not checked: roughness of the motor at 6 rpm. Also not established: the time to standstill within those 4 s, quick stop in mode 3, other rates, reverse or zero targets, enabled mode changes, other firmware.

Node 1's record ends uncertain only because its plan gave the stop one observation (the stop observation uses the run's interval, 5000 ms, against 3500 ms of stop budget). Node 2's plan, 4000 ms against 5000 ms, observed it. The procedure now names node 2's values for both nodes.

End state: both drives enabled in mode 3, halted at 1131 with `60FF=6`; the user switched both drives off at about 09:54Z. No EMCY, `1001=00`, `603F=0000` throughout. The oscilloscope item (transceiver levels across an S2 reset) was declined by the user and not run.
