第二章  参数设置 
2.1 调试软件修改参数 
1、安装调试软件（软件可于官网下载或者找技术） 
打开软件并选择对应型号： 
 
2、进入软件后设置站号和端口号即可，其他参数不需要修改。 
 
3、点击打开端口进行通讯连接，软件左下角显示通讯状态（红色：未连接；绿色：已连接）
，连接成功后点击读取参数后可于参数值栏看到当前参数。 
 
4、修改参数时，于参数值栏找到要修改的参数，设置完参数值以后点击电脑Enter键，然
后点击软件写入参数即可保存参数。

CS命令符：2F:写1个字节；2B:写2个字节；27:写3个字节；23:写4个字节；40:读取参数 
1、 清除当前位置 
索引2302h-00中的值由0变为1时，会将当前位置值清零，需要手动将其置为0； 
SDO报文： 601 : 2B 02 23 00 01 00 00 00 
2、 保存参数 
索引2300h-00中写入2时，会保存驱动器当前参数； 
SDO报文： 601 : 2B 00 23 00 02 00 00 00 
3、 设置电流 
索引2502h-00中可以设置峰值电流，1000对应1A电流； 
SDO报文： 601 : 2B 02 25 00 E8 03 00 00
