第一章 产品介绍 
1.1 产品简介 
CL2 系列步进驱动器是采用最新一代的32 位DSP 芯片，结合我司多年运动控制经验开发的步进
驱动器产品，支持17 位及23 位编码器，包括脉冲型、CANopen 总线、RS485 总线三种控制方式的
产品，本说明书主要介绍CANopen 型驱动器。 
1.2 产品规格 
1、 电压输入范围：DC24V~50V 
2、 最大峰值电流：7A 
3、 适配电机法兰：42/57/60 
4、DI 口输入电流：10~50mA 
5、DI 口输入电压：DC24V 
6、具有过流、过压、位置超差等保护功能

2.4 电机匹配说明 
当匹配力川电机时，不需要额外设置参数匹配电机，接好线正常控制就行，当匹配第三方电机时，需要
设置参数来匹配电机。目前此系列驱动器只支持17 位或者23 位编码器。 
1、 确认好电机额定相电流，编码器类型，首次匹配先不接电机线，只接驱动器供电和编码器线。 
2、 使用Type-C 口连接调试软件，默认站号1，波特率115200，无效验。 
3、 先设置P02.19=1，P00.00=65535，然后设置P00.03_电机额定电流（单位：ma）、P00.12_绝对编码器类
型（0：单圈，1：多圈）、P00.13_电机编码器线束（17 位：131072，23 位：8388608），设置以上参数
后保存重启。 
4、 重启之后读取参数，确保保存成功，参数确认无误，接好线正常控制电机

3.5 其他常用功能 
3.5.1 清除当前位置 
当索引2302h-00 中的值由0 变为1 时，会将当前位置值清零，需要手动将其置为0，此操作可通过SDO 指
令实现。 
3.5.2 保存参数 
通过SDO 往索引2300h-00 中写入2 时，会保存驱动器当前参数，此操作常用来保存回零速度，加减速，回
零模式等参数。 
3.5.2 报警复位 
将控制字6040h-00 的Bit7 置为1，即可复位驱动器报警，需要手动将其置位0。
