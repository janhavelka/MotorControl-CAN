RTU assumptions. Particular hazards include `ActiveSerialTuple`, ESS RPM field

its payload schema is not a CAN protocol specification. Terminal action/motion
outcomes are concrete context members; invented `getActionResult` or
`getMoveResult` names are not copied RS API names.

`files` array. Each file has `source` (path relative to the source repository),
`path` (path relative to this directory), `bytes`, and SHA-256 `sha256`. An
integrity checker must verify every listed file and reject missing, changed,
duplicate or unexpected files under `MotorControl-RS/`. No network access is
needed. Do not silently update copied bytes or regenerate their generated
