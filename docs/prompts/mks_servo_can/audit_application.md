## Unresolved questions

1. **Session and origin continuity without a boot report. Answered in part.** No file establishes continuity across
   an uncommanded power cycle: the protocol reports no boot-up (review section 14 rule 10) and the origin is volatile
   (inference, review section 10), so a fresh 40H read that agrees with the old one proves neither. The revised set
   gives one host-known boundary, a power cycle the caller records with its evidence (02b step 6, 03 step 5), which
   ends the identity session and invalidates the host reference. Which origin-dependent operations stay blocked when
   continuity is not established (05 absolute moves and 07 references rely on a host reference generation) remains
   README open question 3 for the shared contract's owner or the user; V1.0.0's missing 40H stays a separate gate.
2. **Self-echo boundary. Answered by the code.** `adapters/owner/CanBusTypes.h` `Transport::receive` documents "Must
   exclude local self-echo", and `test/twai_driver_test.cpp` asserts that the TWAI adapter enables neither loopback nor
   self-test. The matcher cannot separate an echo from a byte-identical reply, so the old acceptance item "echoed
   request not acknowledged" was not testable at the matcher. 02b step 7 and its acceptance now test transport
   conformance (the fake transport never delivers its own TX) separately from the matcher (a byte-identical success
   frame is matched only after the request's TX disposition, never before the handoff); 04 acceptance follows.
3. **Generator naming and a pre-S4 console exception. Not answered.** `canopen_shared/01_existing_code_and_tooling.md`
   "Intake rules" still names `generate_<family>_objects.py` with `Objects.h` and `Pdo.h`, and canopen_shared's audit
   application question 2 still leaves the `ProbeApp` exception to the prompt 64 lead or the user. README open
   questions 2 and 4 stay; every `mks` console route and API/CLI parity check stays Blocked until S4 (contract 02
   "Console, help and JSONL").
4. **First-power checklist. Answered by the manual.** MK109 p.18 and p.115 (motor internal resistance below 10 Ω,
   radial magnet) and p.20 (common ground, shielded twisted pair) give the missing items; 12A step 1 now lists them
   and treats an unrecorded item as a named gap, not a passed check. Specimen values still come from the fixture.
