### Concrete evidence to recheck

The [object tables](../audit/LICHUAN_OBJECT_FACTS.md) must drive typed command coverage: distinguish observed mode `6061` from requested `6060`, diagnostic `2102` bits0..2 from output commands `60FE` bits16..18, and node-setting `2203` from host selection. The `60FE` bits16..18 sentence is a 57C-body claim with no 86C CANopen-manual support (OP86 pp5-14 are identical to OP57 and are not independent 86C evidence); it applies only to user-defined DOs. Reads follow the Q20 gate (DEC-1): `probe` uses the accepted-read list, and any other object returns the gate error instead of a transmitted read. Print native values with explicit units and unknown/conflicting interpretation. Source conflicts in DO layout, filters or tuning remain capability gates in CLI; a raw command must not bypass typed policy. Use three terms: `save parameters` (`2300=2`), `restore factory settings` (`2300=1`) and `re-apply recorded configuration` (host writes). Keep them explicit separate intents. No vendor restart command is documented; restart here means a user power cycle or a separately gated NMT service whose parameter-reload effect is unknown. Do not call any of them "reset".
